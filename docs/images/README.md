# Documentation image provenance

## `binder-pokedex-v9-key-visual.png`

The room, desk, binder, hand, empty sleeves, lighting, and reflections started
as an AI-assisted, brand-neutral concept photograph. All product content was
then composited locally without a subsequent generative pass:

- the left page uses nine exact cuts reproduced from the promoted Base Set
  master in `assets/posters/Base1/poster-flux2-artwork.png`;
- the right page uses the first nine exact card cuts from page 2 of a freshly
  generated English Base Set PDF;
- positions #002, #004, #006, and #008 replace their printable cut with the
  matching English Base Set card scan from the project's TCGdex source;
- all nine right-hand pocket interiors were measured independently, composed
  at double resolution, edge-feathered, and downsampled to the 1672 × 941 px
  master without redrawing the inserted subjects.

TCGdex documents the high-resolution card asset format used here as
`<image-url>/high.webp`: <https://tcgdex.dev/rest/card> and
<https://tcgdex.dev/de/assets>.
